# Lesson 1.3b · Unsupervised learning: group messages with k-means

**Stage 1 · How machines learn** · Build-first · Time: about 60–75 min · **Project P1** continues

## What you'll build today
A program that splits the 5,574 messages into **groups (clusters)** all by itself, **without ever seeing a label**.
Afterwards you'll bring the labels back, only to *check*, and see whether the computer discovered spam on its own.
(Spoiler: with 4 groups it finds a **98% spam** group, and a group of messages written in capitals that nobody ever labelled.)

You already have both building blocks from 1.3a: **distance** and **scaling**.

**The idea (k-means), in 3 steps:**
```
1. START   put k "centres" somewhere (k = how many groups you want; start with k random messages)
2. ASSIGN  every message joins the group of its NEAREST centre                    ◄─┐
3. MOVE    move each centre to the AVERAGE of the messages in its group             │
           repeat 2 and 3 until the centres stop moving ────────────────────────────┘
```
**How good is a grouping?** Add up every message's squared distance to its own centre. **Smaller = tighter groups.**
This is the "score" (scikit-learn calls it **inertia**). It replaces "count mistakes", because there are no labels to be wrong about.

### Step 1: Scaled vectors (reuse 1.3a)
```python
import math
import random

from sms_data import features, load_sms

labels, texts = load_sms()            # labels are used ONLY at the end, to check
names = list(features("x"))
vectors = [[features(t)[n] for n in names] for t in texts]

mins = [min(col) for col in zip(*vectors)]
maxs = [max(col) for col in zip(*vectors)]

def scale(v):
    return [(x - lo) / (hi - lo) if hi > lo else 0.0 for x, lo, hi in zip(v, mins, maxs)]

points = [scale(v) for v in vectors]  # every message as 7 numbers between 0 and 1

def distance(a, b):
    return math.sqrt(sum((x - y) ** 2 for x, y in zip(a, b)))
```
This is all code you wrote in 1.3a. (Later you could move `scale` and `distance` into a shared module, like `sms_data.py`.)

### Step 2: Two small helpers
```python
def closest_centre(p, centres):
    """Return the NUMBER (0, 1, ...) of the centre nearest to point p."""
    return min(range(len(centres)), key=lambda c: distance(p, centres[c]))

def average(group):
    """The average point of a group: the average of each feature, column by column."""
    return [sum(col) / len(group) for col in zip(*group)]
```
- `min(..., key=...)` works like `sorted(..., key=...)` from 1.3a, but returns only the **smallest** one.
- `zip(*group)` flips the group into columns (one per feature), just like you did for `mins`/`maxs`.
- **Try them:** `print(average([[0, 0], [2, 4]]))` should print `[1.0, 2.0]`. Then delete the test.

### Step 3: Start: pick k random centres
```python
K = 2
random.seed(0)                          # same "random" start every run, so results are repeatable
centres = random.sample(points, K)      # k random messages become the first centres
```

### Step 4: The loop: assign, move, repeat
```python
for step in range(1, 51):                                        # at most 50 rounds
    assignments = [closest_centre(p, centres) for p in points]   # ASSIGN: a group number for every message

    new_centres = []
    for c in range(K):                                           # MOVE each centre
        group = [p for p, a in zip(points, assignments) if a == c]
        new_centres.append(average(group) if group else centres[c])   # empty group? keep the old centre

    score = sum(distance(p, centres[a]) ** 2 for p, a in zip(points, assignments))
    print(f"step {step}: score {score:.1f}")

    if new_centres == centres:                                   # nothing moved, so we're done
        break
    centres = new_centres
```
- `assignments` is a list like `[1, 1, 0, 1, …]`: message 0 is in group 1, message 2 is in group 0, …
- `if group else centres[c]` guards a **tricky case**: a centre that no message chose. `average([])` would divide by zero.

**Run it.** Watch the score **go down every step**, then stop changing. That's k-means improving the groups until it's stuck.

### Step 5: Look inside the groups (now, and only now, use the labels)
```python
print()
for c in range(K):
    members = [l for l, a in zip(labels, assignments) if a == c]
    spam = members.count("spam")
    print(f"cluster {c}: {len(members):>5} messages, spam {spam:>4} ({spam / len(members):.0%})")
    print("   centre:", {n: round(v, 2) for n, v in zip(names, centres[c])})
```
- The **centre** is the "average message" of a group. Reading it tells you **what the group is about**.

**Run it.** Is one cluster spam? Read its centre: which feature is **1.0** in one group and **0.0** in the other? So what did
k-means *actually* split on? (Hint: with scaling, a 0/1 feature makes the biggest possible jump.)

## ② The package version: scikit-learn `KMeans` (≈15 min)
Create `projects/classifier/sk_kmeans.py`:
```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import MinMaxScaler

from sms_data import features, load_sms

labels, texts = load_sms()
names = list(features("x"))
X = [[features(t)[n] for n in names] for t in texts]
X_scaled = MinMaxScaler().fit_transform(X)

for k in [2, 4]:
    km = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X_scaled)   # no y: unsupervised!
    print(f"\nk={k}  score (inertia): {km.inertia_:.1f}")
    for c in range(k):
        members = [l for l, a in zip(labels, km.labels_) if a == c]
        spam = members.count("spam")
        print(f"  cluster {c}: {len(members):>5} messages, spam {spam:>4} ({spam / len(members):.0%})")
```
- **`.fit(X_scaled)` has no `y`.** Compare with `tree.fit(X, y)` in 1.2: that missing `y` is what "unsupervised" means in code.
- `km.labels_` = the group number of each message (your `assignments`). `km.inertia_` = your final score.
- `n_init=10` = run k-means **10 times from different starts and keep the best**. Your version runs it once.

**Run it.** For k=2: same groups and the same score as yours? For k=4: is scikit-learn's score **lower** than yours?

## 📌 Key takeaways
- **k-means:** start with k centres → assign each point to the nearest centre → move centres to their group's average → repeat.
- **Score (inertia)** = total squared distance to own centre. It goes down every step. It replaces "mistakes" when there are no labels.
- k-means groups by **whatever the features make far apart**, not necessarily what you care about (spam). You have to
  **read the centres and look at examples** to understand a group.
- **The random start matters.** One start can get stuck in a worse grouping; scikit-learn tries several (`n_init`).
- **More groups always lower the score**, so "lowest score" can't pick k. Pick the k whose groups are useful.

## 📖 New words
| Word | Meaning in one line |
|------|---------------------|
| Cluster | A group of similar items found without labels. |
| k-means | Clustering by repeating "assign to nearest centre, move centre to the average". |
| Centre (centroid) | The average point of a cluster; reading it tells you what the cluster is about. |
| Inertia | Total squared distance of points to their own centre; smaller = tighter clusters. |
| `n_init` | How many random starts scikit-learn tries; it keeps the best. |
| Converge | When the centres stop moving and the algorithm stops. |
