# Lesson 1.1 · Data, features, and labels: what a computer "sees"

**Stage 1 · How machines learn** · Build-first · Time: about 60–75 min · Starts **Project P1** (spam classifier)

## What you'll build today
A script that downloads **5,574 real text messages**, each one marked by a person as **spam** or **ham**
(ham = a normal, wanted message), and turns every message into **numbers** a computer can learn from.
By the end, you'll *see* with your own numbers why spam is detectable.

**The only theory you need (3 words):**
| Word | Meaning | In today's data |
|------|---------|-----------------|
| **Example** | One item to learn from | One text message |
| **Label** | The right answer for that example | `spam` or `ham` |
| **Feature** | A **number** that describes the example | e.g. how many digits the message has |

A computer can't "read" a message. It only does maths on numbers. **Features turn text into numbers.**
Training a model (Lesson 1.2) means finding patterns that connect the features to the labels.

```
"WIN a FREE prize! Call 09061701461"   ──features──►  [length=35, digits=11, has_free=1, ...]   label: spam
"At home by the way"                    ──features──►  [length=18, digits=0,  has_free=0, ...]   label: ham
```

### Step 2: Download the dataset (once)
The dataset is the **SMS Spam Collection** from the UCI Machine Learning Repository (free for research and learning).
It comes as a `.zip` file.
```python
import zipfile                  # built into Python: opens .zip files
from pathlib import Path        # built into Python: a nicer way to work with file paths

import httpx                    # you know this one from 0.4b

URL = "https://archive.ics.uci.edu/static/public/228/sms+spam+collection.zip"
DATA_DIR = Path("data/sms")                   # a folder path
DATA_FILE = DATA_DIR / "SMSSpamCollection"    # "/" joins paths: data/sms/SMSSpamCollection

if not DATA_FILE.exists():                    # only download if we don't have it yet
    print("Downloading...")
    DATA_DIR.mkdir(parents=True, exist_ok=True)               # create data/sms/ (and data/)
    response = httpx.get(URL, timeout=60, follow_redirects=True)
    response.raise_for_status()                               # stop with an error if not 200
    zip_path = DATA_DIR / "sms.zip"
    zip_path.write_bytes(response.content)                    # save the raw bytes to a file
    with zipfile.ZipFile(zip_path) as z:
        z.extract("SMSSpamCollection", DATA_DIR)              # unzip just the file we need
    print("Saved to", DATA_FILE)
```
- `httpx.get` (not `post`): **GET** means "just give me this file". You're not sending data this time.
- `follow_redirects=True`: if the server says "it moved over there", follow it.
- `raise_for_status()`: a shortcut for the `if status_code != 200` check you wrote in 0.4b.
- **Run it.** Then open `data/sms/SMSSpamCollection` in your editor and look at a few lines. What separates the label from the text?

### Step 3: Read it into two lists
Each line looks like `ham<TAB>Go until jurong point...`. The **tab** character (`\t`) separates the label from the text.
```python
labels = []   # the answers: "spam" or "ham"
texts = []    # the messages

for line in DATA_FILE.read_text(encoding="utf-8").split("\n"):
    label, text = line.split("\t", 1)    # split at the FIRST tab only (remember 0.4a!)
    labels.append(label)
    texts.append(text)

print("Messages:", len(texts))
```
**Run it.** 💥 It crashes! Read the error message. Which line of the file causes it?
*(Hint: what does the very last line of the file contain?)* Fix it by skipping empty lines before splitting:
```python
    if not line.strip():     # strip() removes spaces/newlines; an empty line becomes ""
        continue             # skip to the next line
```
**Run it again.** You should see `Messages: 5574`.

> **Tricky input you just met:** an empty line at the end of a file. Real data is messy. Always ask:
> *what if a line is empty? has no tab? has two tabs?* (This file has exactly one problem line.)

### Step 4: Look at your data
**Rule #1 of all AI work: look at the data before building anything.**
```python
import random   # (move this import to the top with the others)

n_spam = labels.count("spam")
print("spam:", n_spam, "| ham:", labels.count("ham"), f"| spam share: {n_spam / len(labels):.1%}")

random.seed(42)   # makes the "random" picks the same every run, so results are repeatable
for wanted in ["spam", "ham"]:
    print(f"\n--- 3 {wanted} examples ---")
    picks = [t for l, t in zip(labels, texts) if l == wanted]   # all texts with this label
    for t in random.sample(picks, 3):                           # 3 random ones
        print("-", t[:100])                                     # first 100 characters
```
- `zip(labels, texts)` walks through both lists **side by side**: (label 1, text 1), (label 2, text 2), …
- `[t for l, t in ... if l == wanted]` is a **list comprehension**: a one-line loop that builds a list.

**Run it.** Read the examples. (They're real messages, so a few are rude.) What do the spam ones have in common?

**Notice the spam share: only about 13%.** Here's a puzzle for later: a "model" that always answers "ham" would be
right **87%** of the time, while catching **zero** spam. Keep that in mind. It's Lesson 1.5.

### Step 5: Turn a message into features (numbers)
```python
def features(text):
    """Turn one message into numbers."""
    return {
        "length": len(text),                                  # number of characters
        "digits": sum(ch.isdigit() for ch in text),           # how many 0-9 characters
        "exclamations": text.count("!"),
        "uppercase": sum(ch.isupper() for ch in text),        # how many CAPITAL letters
        "has_free": 1 if "free" in text.lower() else 0,       # yes/no as 1/0
    }

print(texts[2])
print(features(texts[2]))
```
- `sum(ch.isdigit() for ch in text)`: `True` counts as 1 and `False` as 0, so summing them counts the digits.
- `has_free` is a **yes/no feature**. Models need numbers, so yes = 1 and no = 0.

**Run it.** Look at a message and its features side by side. **This is all a model would ever see of that message.**

### Step 6: Compare spam vs ham, on average
```python
def averages(wanted):
    rows = [features(t) for l, t in zip(labels, texts) if l == wanted]    # features of every message with this label
    return {name: sum(r[name] for r in rows) / len(rows) for name in rows[0]}

spam_avg = averages("spam")
ham_avg = averages("ham")

print(f"\n{'feature':<14}{'spam':>8}{'ham':>8}")
for name in spam_avg:
    print(f"{name:<14}{spam_avg[name]:>8.2f}{ham_avg[name]:>8.2f}")
```
- `f"{name:<14}"` pads to 14 characters, left-aligned. `>8.2f` means right-aligned, 8 wide, 2 decimals. That makes a neat table.

**Run it.** Which feature is **most different** between spam and ham? That feature is the strongest clue for spotting spam.
**This is the core of machine learning:** when a feature's numbers differ between labels, a model can learn to use them.

|------|---------------------|
| Dataset | A collection of examples (here: 5,574 messages with labels). |
