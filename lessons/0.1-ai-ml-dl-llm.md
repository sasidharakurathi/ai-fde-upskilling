## Why this lesson?

Each circle is a **smaller, more specific** part of the circle around it.
So **every LLM is generative AI, every piece of generative AI is deep learning, and so on**. The
opposite isn't true: not all AI is an LLM.

Let's go from the outside in, using one running example: **sorting emails into spam / not spam.**

---

## 1. Artificial Intelligence (AI): the biggest circle
**Simple meaning:** making computers do things that normally need human thinking, like deciding,
recognising, understanding, or creating.

The **old way** to do AI was for a human to write the **rules** by hand:

```python
if "free money" in email or "click here now" in email:
    mark_as_spam()
```

This counts as AI (the computer "decides"), but it **does not learn**. If spammers write "fr3e m0ney",
the rule fails, and a human has to write a new rule. Forever.

## 2. Machine Learning (ML): learning from examples
**Simple meaning:** instead of writing the rules, you **show the computer lots of examples with the right
answers**, and it **finds the patterns itself**.

```
10,000 emails, each labelled by a human:  "spam" or "not spam"
            │
            ▼
      [ training ]  → the computer finds patterns (certain words, links, senders...)
            │
            ▼
        a MODEL     → a saved "pattern-finder"
            │
            ▼
new email ──► model ──► "spam (93% sure)"
```

Three words to remember:
- **Training:** the learning step, where the computer studies the examples.
- **Model:** what training produces. Think of it as a file full of learned numbers that turns an input
  into an output.
- **Inference:** *using* the trained model on new data. (Every time you send a message to Claude, that's
  inference.)

**Everyday analogy:** a rule-based system is like giving someone a recipe. ML is like letting someone
taste 1,000 dishes until they can tell good cooking from bad on their own.

## 3. Deep Learning: ML with "neural networks"
**Simple meaning:** a kind of ML that uses **neural networks**, which are many layers of simple maths
stacked on top of each other ("deep" = many layers). You'll see how they work in Lesson 1.7.

**Why it matters:** classic ML needs humans to say what to look at ("count the links," "check the
sender"). Deep learning can work directly with **messy, raw data** like photos, sound, and plain text, and
figure out what's important by itself.

Examples: face unlock on your phone, speech-to-text, recognising objects in photos.

## 4. Generative AI: AI that **creates**
Most ML **chooses** or **predicts**: spam or not, cat or dog, the price of a house.
**Generative AI makes new things**: text, images, music, code, video.

Examples: a tool that draws an image from a sentence, or an AI that writes an email for you.

## 5. LLMs (Large Language Models): generative AI for **text**
**Simple meaning:** a very large deep-learning model trained on a huge amount of text to do **one
thing**: guess the **next word** (more exactly, the next "token", a piece of a word, as you'll learn in Lesson 2.1).

It sounds too simple to be useful. But when a model gets very good at guessing the next word, across
almost everything humans have written, it can answer questions, summarise, translate, write code, and
reason through problems.

- **"Large"** = billions of learned numbers inside the model, trained on a huge amount of text.
- **Examples:** Claude (Anthropic), GPT (OpenAI), Gemini (Google), Llama (Meta).
- **Watch out:** ChatGPT and Claude.ai are *apps*. GPT and Claude models are the *LLMs* inside them.

## Where does your old app fit?
Your old app had an **embedding-based similarity** feature. It used an **embedding model**, which is a
deep-learning model that turns text into a list of numbers so that similar meanings get similar numbers.
So it was **deep learning**, but **not generative**: it found similar items and didn't create anything new.
(You'll rebuild it yourself in Lesson 5.1, and this time you'll understand every step.)

## Common confusions
| People say | What's actually true |
|------------|----------------------|
| "AI" (in the news) | Usually means LLMs or generative AI, but AI is much bigger than that. |
| "The AI looked it up" | An LLM doesn't search anything by itself. It generates from patterns it learned, unless *we* give it a search tool (that's RAG and agents, Stages 5 and 9). |
| "AI = robots" | Most AI is just software making predictions. |
| "ML and AI are the same" | ML is one *way* of doing AI: the learning-from-examples way (see below for the other ways). |

### "ML is one way of doing AI." So what are the other ways?
AI is the **goal** (a computer doing something that needs thinking). There are several ways to reach it.
The difference is **where the computer's knowledge comes from**:

| Way | Who provides the knowledge? | Everyday example |
|-----|-----------------------------|------------------|
| **Rules** ("expert systems") | A human writes if-then rules | A bank flags every transfer over $10,000 |
| **Search / planning** | A human gives the goal + the possible moves; the computer tries many options and picks the best | Google Maps choosing the fastest route; old chess computers looking many moves ahead |
| **Logic / knowledge** | A human gives facts; the computer works out new facts from them | "Alice manages Platform" + "Platform follows the on-call policy" → "Alice's team follows the on-call policy" |
| **Machine Learning** | **The computer learns patterns from examples** | Spam filter, face unlock, Claude |

ML became the most popular way because real life is too messy to write rules for (try writing rules for "is this a cat?").
But the other ways are still used, often **together with ML**: a rule that blocks credit-card numbers in an LLM's
answer (Stage 11), an agent that plans steps (Stage 9), an LLM plus a knowledge graph of facts (Stage 8).
Knowing **when a simple rule beats an LLM** (cheaper, faster, exact) is a real skill in both roles.

## 📖 New words
| Word | Meaning in one line |
|------|---------------------|
| AI | Computers doing tasks that normally need human thinking. |
| Machine Learning | Learning patterns from examples instead of hand-written rules. |
| Training | The step where the model learns from examples. |
| Model | The result of training: learned numbers that turn input into output. |
| Inference | Using a trained model on new input. |
| Deep Learning | ML using neural networks with many layers; good with raw data. |
| Generative AI | AI that creates new content. |
| LLM | A large model trained on text to predict the next word (token). |
| Embedding model | A model that turns text into numbers so similar meanings are close together. |
