# ai-fde-upskilling

My learning repo for becoming an **AI Engineer** and/or **Forward Deployed Engineer**. The focus is
consistency and mastery of the fundamentals, not a long syllabus.

## Every day
1. Read yesterday's *First step tomorrow* in `tracking/CHECKINS.md`.
2. Do today's task in `LEARNING_PLAN.md` until its **Done when**.
3. Commit, then check in, either by editing `CHECKINS.md` or by telling Claude one line like
   *"W1D2 done, 50 min, got token counts printing, stuck on uv"*.

Bad day? Do the 15-minute minimum in `tracking/CONSISTENCY.md`. Don't skip.
