AI knowledge. Slow and steady, no deadlines. I build things to learn them; Claude writes the notes.

## Every day
1. Read yesterday's *First step tomorrow* in `tracking/CHECKINS.md`, and do it.
2. Work on the current lesson: read → build → run.
3. Commit and push, then tell Claude *"1.2 done"*. Claude writes the notes, the check-in, and the next lesson.

Bad day? Do the 15-minute minimum in `tracking/CONSISTENCY.md`. Don't skip.
