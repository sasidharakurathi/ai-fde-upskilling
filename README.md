# ai-fde-upskilling

My learning repo for becoming an **AI Engineer** and/or **Forward Deployed Engineer**, starting from zero
AI knowledge. Slow and steady, no deadlines. I move forward when I can explain things in my own words.

## Every day
1. Read yesterday's *First step tomorrow* in `tracking/CHECKINS.md`, and do it.
2. Work on the current lesson: read → try it → explain it back in `notes/my-words.md`.
3. Commit, then check in, either by editing `CHECKINS.md` or by telling Claude something like *"0.1 done, 55 min"*.

Bad day? Do the 15-minute minimum in `tracking/CONSISTENCY.md`. Don't skip.
